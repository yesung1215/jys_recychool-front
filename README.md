# ♻️ Recycool

> **폐교 자원을 활용한 예약 기반 공간 대여 플랫폼**

Recycool(리싸이쿨)은  
폐교 시설을 활용하여 장소·주차 공간 등을 예약하고  
일정과 위치 정보를 함께 제공하는 **공공 자원 활용 웹 서비스**입니다.

## 📌 프로젝트 개요

- **프로젝트명**: Recycool
- **개발 기간**: 2024.10 ~ 2024.12(약 2개월)
- **형태**: 팀 프로젝트 (Frontend / Backend 분리)
- **담당 역할**: 예약 / 캘린더 / 지도 기능 프론트엔드 개발

## 🛠 기술 스택

- React
- Styled-components
- React Query
- MUI (Calendar)
- Google Maps API

## ✨ 주요 기능

- 장소 / 주차 공간 예약 CRUD
- 예약 일정 캘린더 시각화
- 학교 위치 지도 표시
- 예약 상태별 UI 분기 처리

## 🧯 트러블슈팅

### 1. 예약 유형별 API 분기 처리 중 데이터가 정상적으로 조회되지 않던 문제

- **문제**  
  장소 예약과 주차 예약이 서로 다른 API를 사용하고 있어  
  예약 유형에 따라 데이터 조회가 실패하는 문제가 발생함

- **원인**  
  예약 타입별로 API 엔드포인트가 분리되어 있으나  
  프론트에서 이를 공통 로직으로 처리하려다 분기 처리가 누락됨

- **해결**  
  예약 타입을 기준으로 API 호출 로직을 분리하고  
  공통 컴포넌트에서는 타입만 전달하도록 구조를 개선함

- **배운 점**  
  도메인이 다른 데이터는  
  **무리한 공통화보다 명확한 분리 설계가 더 중요함**을 체감함
