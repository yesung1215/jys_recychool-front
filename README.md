# ♻️ Recychool

> **폐교 자원을 활용한 예약 기반 공간 대여 플랫폼**

Recychool(리싸이쿨)은  
폐교 시설을 활용하여 장소·주차 공간 등을 예약하고  
일정과 위치 정보를 함께 제공하는 **공공 자원 활용 웹 서비스**입니다.

## 📌 프로젝트 개요

- **프로젝트명**: Recychool
- **개발 기간**: 2024.10 ~ 2024.12(약 2개월)
- **형태**: 팀 프로젝트 (Frontend / Backend 분리)
- **담당 역할**: 예약 / 캘린더 / 지도 기능 프론트엔드 개발

## 🛠 기술 스택

- React
- Styled-components
- React Query
- MUI (Calendar)
- Google Maps API

## ✨ 주요 기능

- 장소 / 주차 공간 예약 CRUD
- 예약 일정 캘린더 시각화
- 학교 위치 지도 표시
- 예약 상태별 UI 분기 처리

## 🧯 트러블슈팅

### 1. 예약 유형별 API 분기 처리 중 데이터가 정상적으로 조회되지 않던 문제

- **문제**  
  장소 예약과 주차 예약이 서로 다른 API를 사용하고 있어  
  예약 유형에 따라 데이터 조회가 실패하는 문제가 발생함

- **원인**  
  예약 타입별로 API 엔드포인트가 분리되어 있으나  
  프론트에서 이를 공통 로직으로 처리하려다 분기 처리가 누락됨

- **해결**  
  예약 타입을 기준으로 API 호출 로직을 분리하고  
  공통 컴포넌트에서는 타입만 전달하도록 구조를 개선함

- **배운 점**  
  도메인이 다른 데이터는  
  **무리한 공통화보다 명확한 분리 설계가 더 중요함**을 체감함

### 2. 예약 상세 패널에서 날짜 변경 시 정보가 즉시 반영되지 않던 문제

- **문제**  
  캘린더에서 날짜를 변경했을 때  
  우측 예약 상세 패널에 이전 날짜의 정보가 남아 있는 현상 발생

- **원인**  
  선택된 날짜 상태가 캘린더 컴포넌트와  
  상세 패널 컴포넌트 간에 분리되어 있어  
  상태 동기화가 이루어지지 않음

- **해결**  
  선택 날짜 상태를 상위 컴포넌트로 끌어올려  
  단일 상태로 관리하고,  
  props를 통해 하위 컴포넌트에 전달하도록 구조를 수정함

- **배운 점**  
  화면 간 연관된 상태는  
  **단일 소스(Single Source of Truth)로 관리해야 한다는 점**을 체감함
